# G2F Diagnostic Benchmarking Portfolio

This is a public-facing portfolio hub for a computational re-analysis of the Genomes to Fields (G2F) maize genotype-by-environment prediction competition.

The project reframes G2F competition outputs as a diagnostic benchmarking problem: instead of asking only which model ranks highest, it asks how model performance can be decomposed into environment calibration, hybrid ranking, environmental feature correction, and data-coverage failure modes.

## Live entry point

Open `index.html` in this directory, or visit the GitHub Pages route after deployment:

`/g2f-diagnostic-benchmarking/`

## What this portfolio shows

- A polished single-page project hub.
- Selected M1-M7 visual reports.
- Manuscript-style figure previews.
- Diagnostic views for target environments, harmful overcorrection, CUSUM stress episodes, validation-weighted gating, and hybrid-level failure modes.

## What is not included

- Raw G2F competition data.
- Full working-layer outputs.
- Manuscript drafts.
- Private research notes.
- Large reproducibility artifacts.

This repository folder is intended as a concise portfolio showcase, not as the full research reproducibility archive.

## Project framing

This project is for people who care about robust GxE prediction, model diagnostics, and breeding decision support. It uses public G2F competition outputs and derived visual summaries to make model behavior easier to interpret across environments and hybrids.
