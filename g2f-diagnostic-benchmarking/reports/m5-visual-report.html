M5 Environment-Covariate Visual Report

M5 tests whether metadata, weather, soil and crop-model-derived EC layers improve target-environment mean calibration beyond M3 site history. Hyperparameters are selected using historical training validation only; post-competition observed target values are used only for retrospective scoring, error-shift maps and failure diagnostics.

Environmental covariates contain useful signal, but direct correction is risky. The scientific question is not "do weather/soil/EC features improve prediction?", but "when should the model trust these features enough to move the environment mean?"
