# Plant Breeding Bootcamp

This repository documents a self-directed two-month learning project in computational plant breeding. The project is designed to build a strong foundation for future graduate study in plant breeding, quantitative genetics, and crop data science.

The bootcamp covers classical plant breeding, quantitative genetics, genotype-by-environment interaction, BLUP-based modeling, genomic selection, and a final Genomes to Fields (G2F) prediction project.

## Project Goals

- Build a structured foundation in classical plant breeding and crop improvement.
- Understand the quantitative genetic principles behind selection, heritability, breeding values, and genetic gain.
- Learn how genotype-by-environment interaction affects cultivar performance and breeding decisions.
- Practice BLUP and mixed-model thinking for multi-environment breeding data.
- Develop beginner-friendly computational workflows using R, Python, and GitHub.
- Complete a final portfolio project focused on G2F genotype-by-environment prediction.

## Weekly Roadmap

| Week | Topic | Focus |
| --- | --- | --- |
| Week 1 | Classical plant breeding foundations | Breeding goals, selection, crossing, field trials, and variety development |
| Week 2 | Quantitative genetics | Heritability, genetic variance, selection response, and breeding values |
| Week 3 | Genomics and marker data | SNP markers, genotype matrices, quality control, and marker-based analysis |
| Week 4 | Phenotypes and environments | Trait data, environmental covariates, field trial design, and data quality |
| Week 5 | BLUP and mixed models | Fixed effects, random effects, BLUP, and breeding value prediction |
| Week 6 | Genomic selection | Genomic prediction, GBLUP, cross-validation, and prediction accuracy |
| Week 7 | GxE and G2F data | Genotype-by-environment interaction and G2F project planning |
| Week 8 | Final portfolio synthesis | Final analysis, documentation, figures, and research reflection |

## Learning Outcomes

By the end of this project, I aim to be able to:

- Explain the major stages of a plant breeding program.
- Describe how quantitative traits are inherited and selected.
- Interpret heritability, genetic variance, breeding values, and selection response.
- Explain why genotype-by-environment interaction matters in crop improvement.
- Use BLUP and mixed-model concepts to analyze breeding data.
- Describe the logic of genomic selection and genomic prediction.
- Build reproducible analysis workflows for phenotype, genotype, and environment data.
- Communicate computational plant breeding results in a clear, research-oriented format.

## Tools Used

- **R**: statistical modeling, mixed models, genomic prediction, and visualization.
- **Python**: data cleaning, exploratory analysis, machine learning, and workflow support.
- **GitHub**: version control, project organization, documentation, and portfolio presentation.

## Final G2F Prediction Project

The final project focuses on genotype-by-environment prediction using public Genomes to Fields data. The guiding question is:

> How well can genotype, phenotype, and environmental information predict maize performance across environments?

The project will connect biological motivation with statistical modeling by exploring how GxE affects prediction and how computational tools can support breeding decisions.

## Final Deliverables

- Weekly Markdown notes and summaries.
- A curated `references.md` file with papers, datasets, and software resources.
- Reproducible R and/or Python code for data cleaning, modeling, and visualization.
- A final G2F project README with research question, data description, methods, and interpretation.
- A data dictionary for phenotype, genotype, and environmental variables.
- Model comparison results for baseline, BLUP-based, and genomic prediction approaches.
- Figures or tables summarizing data structure, GxE patterns, and prediction performance.
- A final reflection connecting the project to future computational plant breeding PhD goals.

## Portfolio Purpose

This repository is intended to demonstrate research readiness: the ability to learn independently, organize scientific material, write reproducible code, and connect plant breeding theory to real agricultural data analysis.
