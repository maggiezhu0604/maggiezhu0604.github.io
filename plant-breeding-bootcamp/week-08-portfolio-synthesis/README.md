# Week 8: Portfolio Synthesis

## Focus

This week turns the bootcamp work into a coherent portfolio artifact with clean documentation, reproducible code, and a clear research narrative.

## Learning Goals

- Organize a computational biology project for external readers.
- Write a concise scientific project README.
- Present methods and results with appropriate caution.
- Identify future directions for PhD-level research.

## Suggested Activities

- Clean the final project folder.
- Write a project abstract.
- Prepare figures, tables, and a reproducibility checklist.
- Review the repository as if it were being read by a potential advisor.

## Portfolio Output

Complete the final project README and include:

- Motivation.
- Data sources.
- Methods.
- Results or planned analysis.
- Limitations.
- Next steps.
