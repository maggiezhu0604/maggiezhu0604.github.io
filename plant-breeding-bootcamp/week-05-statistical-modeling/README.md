# Week 5: Statistical Modeling For Breeding Data

## Focus

This week introduces baseline statistical models for breeding data, including linear models, mixed models, cross-validation, and model evaluation.

## Learning Goals

- Fit and interpret a simple linear model.
- Explain fixed effects and random effects at a beginner level.
- Understand training, validation, and test sets.
- Choose basic evaluation metrics for prediction.

## Suggested Activities

- Build a small simulated dataset.
- Fit a baseline model using R or Python.
- Compare model predictions with observed phenotypes.

## Portfolio Output

Create one small baseline modeling notebook or script in `code/` and summarize:

- The modeling question.
- The variables used.
- The evaluation metric.
- What the model can and cannot tell us.
