# Code

Use this folder for scripts, notebooks, and reusable analysis utilities.

Suggested organization:

```text
code/
├── README.md
├── data-cleaning/
├── exploratory-analysis/
├── modeling/
└── visualization/
```

Recommended practices:

- Keep scripts small and readable.
- Use comments to explain biological or statistical decisions.
- Save exploratory work separately from polished final analysis.
- Record package versions when results become part of the final project.
