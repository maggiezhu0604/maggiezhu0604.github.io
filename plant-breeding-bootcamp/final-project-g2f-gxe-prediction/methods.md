# Methods

## Data Selection

Document the G2F years, traits, environments, and genotypes selected for analysis.

## Data Cleaning

Record decisions about missing values, outliers, genotype filtering, environment filtering, and trait transformations.

## Modeling

Start with a baseline model before adding complexity. For example:

- Environment-only baseline.
- Genotype and environment model.
- Genomic prediction model.
- Model with environmental covariates.

## Evaluation

Use cross-validation strategies that match the breeding question:

- Predicting tested genotypes in observed environments.
- Predicting new genotypes.
- Predicting new environments.
- Predicting future years.

## Interpretation

Explain prediction accuracy in biological and breeding terms, not only as a statistical metric.
