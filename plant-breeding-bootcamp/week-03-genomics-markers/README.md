# Week 3: Genomics And Molecular Markers

## Focus

This week introduces marker data, genome-wide variation, linkage disequilibrium, and the role of genotyping in modern plant breeding.

## Learning Goals

- Describe common marker types, including SNPs.
- Understand genotype matrix structure.
- Recognize common marker quality control steps.
- Explain how marker data can support genomic prediction.

## Suggested Activities

- Inspect a small genotype matrix.
- Draft a marker quality control checklist.
- Read about genome-wide marker panels in plant breeding.

## Portfolio Output

Create `marker-data-glossary.md` with:

- Definitions for SNP, allele, genotype call, missingness, minor allele frequency, and imputation.
- A short checklist for preparing marker data for analysis.
