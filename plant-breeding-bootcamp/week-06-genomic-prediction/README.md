# Week 6: Genomic Prediction

## Focus

This week connects marker data and phenotype data to genomic prediction, with emphasis on prediction accuracy and breeding decision support.

## Learning Goals

- Explain the purpose of genomic selection.
- Describe the difference between marker-assisted selection and genomic selection.
- Understand genomic relationship matrices at a conceptual level.
- Compare simple genomic prediction workflows.

## Suggested Activities

- Read an introductory genomic selection paper.
- Sketch a workflow from marker matrix to predicted breeding value.
- Compare possible tools such as `rrBLUP`, `BGLR`, or `sommer`.

## Portfolio Output

Create `genomic-prediction-workflow.md` with:

- Input data requirements.
- Modeling steps.
- Evaluation strategy.
- Potential limitations for small or noisy datasets.
